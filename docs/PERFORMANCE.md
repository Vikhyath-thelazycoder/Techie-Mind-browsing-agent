## Principles carried forward

- Deterministic actions make **zero** model calls (spec §59).
- Vision model is lazy-loaded only when DOM/A11y is insufficient (spec §12, §61).
- Nothing heavy is injected into web pages; per-page footprint is budgeted and gated.

## Phase 1 — agent latency (measured 2026-09-28)

All tasks: **0 model calls** (Tier 0 deterministic). Stage timings sum to 96–99% of each task's total (the rest is tab preparation and pre-action probes). Evidence: `evidence/perf-phase1-fixtures.json`, `evidence/phase1-live.json`.

### Local fixture sites — 20 tasks, 10 queries × 2 sites (real Chromium, no network)

| Stage | P50 | P95 |
|---|---|---|

### Live sites — Tests A, B, C and variations V1–V4 (youtube.com, flipkart.com)

| Stage | min | median | max |
|---|---|---|---|
| Intent resolution | 5.1 ms | 5.3 ms | 5.7 ms |
| Navigation (real page load + settle) | 1,431 ms | 1,533 ms | 1,954 ms |
| Observation | 26 ms | 38 ms | 109 ms |
| Grounding | 0.2 ms | 0.4 ms | 0.5 ms |
| Action execution | 4.8 ms | 10.8 ms | 14.5 ms |
| Verification | 1.4 ms | 1.9 ms | 2.7 ms |
| Waiting for the page to react | 1,009 ms | 1,012 ms | 1,633 ms |
| **Complete task** | **2,510 ms** | **2,731 ms** | **3,642 ms** |

**Reading:** the agent's own work (intent + observation + grounding + action + verification) is ~50 ms per task on live sites; ~95% of latency is the websites loading and reacting. The waiting stage is dominated by the settle rule (DOM quiet for 300 ms intervals) — the clearest optimisation target for Phase 12.

### Footprint

- Ordinary browsing: **0 bytes** of Techie Mind code in web pages (no declared content scripts).
- Agent tab: content script injected on demand — 123.9 KB raw / 37.0 KB gzip.
- No screenshot capture and no VLM in the loop (spec §59).

## Phase 1 correction — impact (measured 2026-09-28)

- Fixtures (20 tasks): total P50 1,039 ms / P95 1,054 ms (before 1,039 / 1,050). Context inspection 0.2 ms; resolution 0 ms when no name is resolved.
- Live reuse (no navigation, tests E–I): 1.3–4.8 s end to end.
- Live resolution: 0.6–1.4 s when background probes decide; ≤4.5 s probe ceiling otherwise; cached repeats probe nothing.
- Busy-page settle (2.5 s stable load) cut Nike from 24.7 s to 10–12 s.

## Phase 2 — privacy scan and firewall cost (measured 2026-09-28)

Fixtures (20 tasks): total P50 1,050 ms / P95 1,063 ms vs the frozen Phase 1 baseline 1,039 / 1,050 ms (+1.0% / +1.2%; budget +15%). Privacy scanning (observation sanitize + in-page text scan) P50 2.1 ms / P95 6.4 ms per task; firewall (including its live probe) P50 2.0 ms / P95 3.0 ms per task. Baseline: `evidence/perf-phase1-baseline.json`.
